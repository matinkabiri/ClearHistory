# Clear Recent Activity

A native WPF utility for reviewing and clearing Windows Recent Items shortcuts. It never opens or deletes the target files. The default time range is the last 24 hours and **Dry run** is enabled on first launch.

## Run

Requires Windows and the .NET 8 SDK.

```powershell
dotnet run --project ClearHistory.csproj
```

Build output: `bin\Debug\net8.0-windows\ClearHistory.exe`.

The project root also contains a Release build's `ClearHistory.exe` for convenience. It requires the .NET 8 Desktop Runtime. GitHub Releases are created automatically for tags named `v*`; the attached x64 package is self-contained.

## Sources and safety limits

| Source | Discovery / timestamp | Selective clear |
|---|---|---|
| `%APPDATA%\Microsoft\Windows\Recent\*.lnk` | WScript Shell resolves the shortcut target. The shortcut file's modified time is used as a proxy for recency; Windows does not expose a dependable last-opened timestamp for each entry here. | Yes. The app deletes only the exact previewed `.lnk` files in this folder. |
| `AutomaticDestinations` | Per-app Jump List binary databases. They may include recent/frequent lists and app-owned state. Public JumpList APIs only operate on the current packaged app and do not reveal a cross-app list with dependable per-entry access times. | No. Rewriting these databases risks pinned/custom app data and cannot meet exact preview parity. |
| `CustomDestinations` | App-managed binary Jump List stores; may mix pinned and custom groups with recent items. | No. No general supported selective-clear interface. |
| Start Recommended | Windows 11 recommendations are generated by shell activity and app/provider data; the app does not expose a general supported per-item timestamped delete API. | No. The classic Recent Items shortcuts can appear there, but clearing them does not promise to remove every recommendation. |

The app intentionally limits clearing to the Recent Items shortcuts it can resolve and preview. The Preview table is the deletion target list. Unresolvable shortcuts are skipped. The operation log is stored at `%LOCALAPPDATA%\ClearHistory\operations.log`. Windows may cache views of recent history; refresh Explorer or sign out if the shell continues showing a removed shortcut. Other Jump List and Start recommendation data may remain.

## Architecture

- `RecentDiscovery`: reads Recent Items shortcuts and resolves targets.
- `CategoryRow` / `HistoryEntry`: category and preview models.
- `MainWindow`: range filtering, preview, confirmation, dry run, deletion report, and operation logging.
- WPF UI: native Windows desktop controls, independent category selection, time range selection, and preview grid.

Deletion is limited to the preview's shortcut paths; it does not call the broad `SHAddToRecentDocs(NULL)` clear operation.
